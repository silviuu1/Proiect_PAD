# Proiect_PAD

Repository creat în cadrul disciplinei **Planificarea Aplicațiilor Desktop** 
pentru exersarea controlului versiunilor cu Git și GitHub.

## Structura proiectului
- `aplicatie.cpp` – fișierul sursă principal al aplicației
- `.gitignore` – reguli pentru excluderea fișierelor locale private (`parole.txt`)

## Tehnologii utilizate
- Git & Git Bash (gestionare locală a versiunilor)
- GitHub (găzduire și documentare în cloud)
